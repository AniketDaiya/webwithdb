# Walkthrough: GenAI & Context Engineering Mastery Bootcamp

I have successfully built a premium, fully functional landing page and course web application. The design is inspired by the "MindX" aesthetic, featuring a sophisticated blue-gradient palette, glassmorphism, and a high-fidelity hero section.

## 🌟 Key Features

### 1. Premium UI/UX
- **Glassmorphism**: All cards and sections use a semi-transparent, blurred background for a modern look.
- **Bento Grid**: The "Why This Course" section uses a responsive bento grid to highlight key features.
- **Animated Background**: A CSS-based mesh gradient with moving "blobs" creates a dynamic, high-end feel.

### 2. Interactive 7-Day Syllabus
- **Search & Filter**: Users can search for specific topics (e.g., "RAG", "Prompts") to find relevant days.
- **Accordion Logic**: Each day is expandable, showing detailed goals, topics, and mini-projects.
- **Progress Tracking**: A seat availability bar and countdown timer create urgency and a realistic "bootcamp" feel.

### 3. PDF Integration
- **Direct Link**: All "Handbook" buttons link directly to your Google Drive PDF.
- **Modal Viewer**: A premium modal window provides details about the handbook before viewing.

### 4. Functional Tools
- **Dark/Light Mode**: A toggle in the navigation bar allows users to switch themes seamlessly.
- **Responsive Menu**: The site is fully optimized for Mobile, Tablet, and Desktop.
- **Sticky Nav**: Smooth navigation with a "Back to Top" button for long-scroll usability.
